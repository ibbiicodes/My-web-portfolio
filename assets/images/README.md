# Assets & Images Directory

Place your custom portfolio images, profile pictures, and project screenshots in this folder.

### Recommended Dimensions:
- **Profile / Avatar**: `assets/images/avatar.jpg` (Square or 4:5 aspect ratio, e.g. 800x1000px)
- **Project Screenshots**: `assets/images/projects/` (16:9 aspect ratio, e.g. 1920x1080px or 1280x720px)

### How to use local images:
In `js/data/siteConfig.js`:
```javascript
avatar: "assets/images/avatar.jpg",
```

In `js/data/projects.js`:
```javascript
image: "assets/images/projects/project-1.jpg",
```
